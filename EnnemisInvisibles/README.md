# Ennemis Invisibles — mod ULTRAKILL

Rend **tous les ennemis invisibles** (boss compris). Ils restent là, ils t'attaquent,
ils saignent… mais tu ne les vois plus. Bonne chance.

## Touches

| Touche | Action |
|---|---|
| **F10** | Activer / désactiver l'invisibilité |

## Configuration

`BepInEx\config\com.ennemisinvisibles.ultrakill.cfg`

- `HideEffects` : cacher aussi les effets des ennemis (particules, flash d'attaque, aura
  radiante…). Désactivé par défaut : seul le corps est invisible, tu peux encore deviner
  les attaques. Mets `true` pour le mode vraiment aveugle.
